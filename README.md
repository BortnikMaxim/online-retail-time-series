# Анализ продаж VINTAGE SNAP CARDS

Исследование недельных продаж товара **VINTAGE SNAP CARDS**, `StockCode = 21790`, на данных Online Retail. В [ноутбуке](analysis.ipynb) сохранены расчёты, графики и разбор результатов. Основные функции загрузки, агрегации и диагностики собраны в [retail_ts.py](retail_ts.py).

## Что получилось

- **Агрегация.** С 1 декабря 2010 г. по 9 декабря 2011 г. в журнале зафиксировано **14 528 шт.** Продажи посчитаны по дням, неделям и месяцам как сумма положительных количеств в строках с положительной ценой без отмен. На недельной частоте относительный разброс ниже, чем на дневной, а для месячного анализа доступно всего 12 полных месяцев.
- **Покрытие и пики.** В нужных полях исходной таблицы пропусков нет. В 24 дня магазин продавал другие товары, но этот товар не продавался. Ещё в 69 дней в журнале нет продаж по всему магазину, в том числе с 24 декабря по 3 января. Эти дни помечены отдельно. Верхний порог Тьюки отметил 32 дня. Например, из 384 шт. 9 сентября 360 пришлись на один счёт. Пики сохранены, интерполяция не применялась.
- **Динамика и сезонность.** В 48 полных неделях основного отрезка медиана выросла со 101,5 шт. в I квартале до 488 шт. в наблюдаемой части IV квартала. Робастная STL и дневная автокорреляция показывают умеренный рисунок с периодом 7 дней (ACF на лаге 7 — 0,225, сила сезонной компоненты — 0,177). Часть рисунка связана с отсутствием продаж по субботам. Для проверки годовой сезонности история слишком короткая.
- **Стационарность.** Исходные недельные суммы не согласуются со стационарностью вокруг постоянного уровня (ADF: p = 0,2741, KPSS: p < 0,01). После первой разности `log1p` результаты согласуются со стационарностью (ADF: p ≈ 4,44 × 10⁻⁹, KPSS: p > 0,10), а разброс двух половин ряда становится ближе. Проверка с линейным трендом показывает, что на логарифмической шкале имеет смысл сравнить дифференцирование с моделью явного тренда.

## Как воспроизвести

Из корня проекта, с Python 3.11:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyter lab analysis.ipynb
```

В JupyterLab выберите **Restart Kernel and Run All Cells**. При первом запуске файл загружается с UCI и сохраняется в `data/`. Если автоматическая загрузка недоступна, скачайте `Online Retail.xlsx` со страницы UCI и положите его в `data/` под исходным именем. Код проверит контрольную сумму файла.

Тот же прогон из терминала:

```bash
python -m jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=240 analysis.ipynb
```
